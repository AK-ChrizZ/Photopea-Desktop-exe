## 📥 Installation & Download

Für die normale Nutzung musst du **kein** Node.js oder Electron installiert haben. Alles ist bereits startbereit verpackt!

1. Klicke rechts auf der GitHub-Seite auf **Releases**.
2. Lade dir die neueste Datei **`Photopea.rar`** herunter.
3. Entpacke die heruntergeladene RAR-Datei (z. B. mit WinRAR oder 7-Zip).
4. Öffne den entpackten Ordner und starte das Programm per Doppelklick auf die **`Photopea Starten Verknüpfung`**.

Die Verknüpfung kann auch einfach auf den Desktop gezogen werden.

---

## 📥 Installation & Download (English)

You **do not** need Node.js or Electron installed for normal use. Everything comes pre-packaged and ready to go!

1. Look at the right sidebar of this GitHub page and click on **Releases**.
2. Download the latest **`Photopea.rar`** file.
3. Extract the downloaded RAR file (e.g., using WinRAR or 7-Zip).
4. Open the extracted folder and double-click **`Photopea Starten Verknüpfung`** to launch the program.

The shortcut can also simply be dragged and dropped onto your desktop.
